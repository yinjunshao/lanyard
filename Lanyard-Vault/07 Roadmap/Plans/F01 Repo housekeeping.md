# F01 Repo housekeeping

**Priority:** P0 · **Phase:** 0 Quick fixes · **Size:** S · **Needs:** nothing · back to [[00 Master To-Do]]

## Why
The `.gitignore` in the project folder is still the old one. An earlier session updated a stale copy outside the project, so none of those rules reached this repo. Several large or generated files sit in the project root and may be tracked or pushed by mistake.

## Current state
- `.gitignore` ignores `node_modules`, `dist`, `.dev.vars`, `.wrangler/`, `.migrations/`, `cloudflared.exe`, editor files and logs.
- The root also holds `brag-output/`, `brag-output-2026-10-27-012233/`, `demo-v1/`, `logo-concepts/`, `logo-kit/`, `Lanyard-pitch.pptx` (700 KB, generated by `build-deck.mjs`), `.claude/launch.json`, `Lanyard-Vault/` (this vault, including `.obsidian/workspace.json`, which changes every time Obsidian opens).

  - caches: `.vite/`, `.cache/`, `.eslintcache`, `coverage/`
  - generated: `brag-output-*/` (timestamped render copies), `*.pptx` (rebuilt by `build-deck.mjs`), `*.zip`, `*.tar.gz`, `*.exe`
