# Lanyard: project vault

> Remember everyone you meet. Lanyard is a free, no-download QR badge for networking events. Two people scan, take a shared selfie, and each keeps the other's face, name and what they can help with. Event hosts pay.

Live at **lanyd.fyi**. Vault last built 2026-11-01 from the project folder (docs, code, migrations, git history). Where a fact is not in the project files it is marked **TODO** or **Unknown**, not guessed.
