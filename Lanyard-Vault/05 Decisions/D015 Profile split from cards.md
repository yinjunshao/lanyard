# D015 Profile split from cards

**Status:** Accepted  ·  **Date:** 2026-10-16

## Context
One person needs different faces for careers fair, hackathon and social.

## Decision
One profile holds everything; any number of cards (3 free, 12 on Plus) each choose links, tags, note, theme and optionally an event.

## Consequences
More UI to build; covers professional, educational and social use without multiple accounts.

**Evidence:** Product plan 'Key feature: per-event cards', migrations/0001 (cards)
